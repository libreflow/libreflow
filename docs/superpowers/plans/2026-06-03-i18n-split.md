# i18n Split Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Séparer `i18n.js` (1538 lignes) en trois fichiers : deux dictionnaires de données purs (`i18n.fr.js`, `i18n.en.js`) et un module de logique (~90 lignes).

**Architecture:** Extraction pure — aucune logique modifiée. `LANGS`, `i18n`, `initLang`, `setLang`, `getLang`, `applyLang` restent exportés depuis `i18n.js`. Les call sites ne changent pas.

**Tech Stack:** Vanilla ESM JS, Node 20, `npm test`

**Spec:** `docs/superpowers/specs/2026-06-03-architecture-module-split-design.md` §3

**Test commands:**
- `npm test` → `node frontend/tests/core.test.cjs`

## Task 1 : Créer `i18n.fr.js`

**Files:**
- Create: `frontend/src/i18n.fr.js`

- [ ] **Step 1 : Créer le fichier avec le dict français**

Créer `frontend/src/i18n.fr.js` avec ce contenu exact :

```
// LibreFlow — i18n.fr.js
// Dictionnaire français. Importé par i18n.js uniquement.
// Ne pas ajouter d'imports ici — ce fichier est data pure.

export const fr = {
  <copier les lignes 16 à 714 de frontend/src/i18n.js telles quelles>
}
```

Les lignes 16-714 de `i18n.js` sont les entrées du dict `fr`, du premier commentaire `// Nav` jusqu'à l'entrée `err_tag_timeout`. La ligne 715 de l'original est `  },` (fermeture de `fr`) — ne pas la copier. Terminer le fichier par `}` seul sur la dernière ligne.

- [ ] **Step 2 : Vérifier la syntaxe**

```powershell
node --input-type=module --eval "import('./frontend/src/i18n.fr.js').then(m => console.log('OK', Object.keys(m.fr).length, 'clés fr'))"
```

Attendu : `OK 250 clés fr` (nombre entre 200 et 350).

## Task 2 : Créer `i18n.en.js`

**Files:**
- Create: `frontend/src/i18n.en.js`

- [ ] **Step 1 : Trouver la dernière ligne du dict `en`**

```powershell
Select-String -Path frontend/src/i18n.js -Pattern "let lang" | Select-Object -First 1
```

Ceci donne le numéro de ligne de `let lang = 'fr'`. Le dict `en` se termine deux lignes avant (une ligne `  },` et une ligne `}` fermant LANGS). Retenir ce numéro.

- [ ] **Step 2 : Créer le fichier avec le dict anglais**

Créer `frontend/src/i18n.en.js` avec ce contenu exact :

```
// LibreFlow — i18n.en.js
// English dictionary. Imported by i18n.js only.
// No imports here — pure data file.

export const en = {
  <copier les lignes 717 jusqu'à (N-3) de frontend/src/i18n.js, où N est la ligne de `let lang`>
}
```

La ligne 716 de l'original est `  en: {` — ne pas la copier (elle devient l'en-tête `export const en = {`). Copier uniquement les entrées du dict. Terminer par `}`.

- [ ] **Step 3 : Vérifier la syntaxe**

```powershell
node --input-type=module --eval "import('./frontend/src/i18n.en.js').then(m => console.log('OK', Object.keys(m.en).length, 'en keys'))"
```

Attendu : nombre de clés proche du résultat de Task 1 (les deux dicts ont les mêmes clés).

## Task 3 : Réécrire `i18n.js`

**Files:**
- Modify: `frontend/src/i18n.js`

- [ ] **Step 1 : Remplacer le bloc LANGS par les imports**

Dans `frontend/src/i18n.js`, supprimer les lignes 14 à la ligne précédant `let lang = 'fr'` (inclus le `}` fermant LANGS et la ligne `  },` fermant `en`).

Les remplacer par ces 4 lignes exactes (juste après le bloc d'imports existants) :

```js
import { fr } from './i18n.fr.js'
import { en } from './i18n.en.js'

export const LANGS = { fr, en }
```

Résultat : le fichier commence par les imports originaux (lignes 1-12), puis les deux nouveaux imports, puis `export const LANGS = { fr, en }`, puis la ligne vide, puis `let lang = 'fr'` et toute la logique jusqu'à la fin.

- [ ] **Step 2 : Vérifier le nombre de lignes**

```powershell
(Get-Content frontend/src/i18n.js | Measure-Object -Line).Lines
```

Attendu : entre 80 et 130 lignes.

- [ ] **Step 3 : Smoke test Node**

```powershell
node --input-type=module --eval "
import { LANGS, i18n, initLang, setLang, getLang } from './frontend/src/i18n.js'
console.log('LANGS keys:', Object.keys(LANGS).join(', '))
```
