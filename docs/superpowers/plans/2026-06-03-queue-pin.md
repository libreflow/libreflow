# Queue Pin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a pin toggle to the queue panel header so the queue stays open across sessions (≥ 720 px only), persisted in cfg.

**Architecture:** A boolean `queuePinned` in the runtime store + IDB cfg drives everything. `toggleQueuePin()` in `queue.js` handles UI state; handlers.js owns the cfg save. Boot restore in `app.js` reopens the queue if pinned. The `#app.panel-queue-pinned` CSS class reuses the same `padding-right` formula as the existing `panel-queue-open` class.

**Tech Stack:** Vanilla JS ESM, CSS custom properties, IDB via cfgsave.js

## Task 3: queue.js — add `toggleQueuePin()` and `clearQueuePin()`

**Files:**
- Modify: `frontend/src/queue.js` (after `closeQueue()`, around line 257)

- [ ] **Step 1: Insert the two functions after `closeQueue()`**

Find the closing `}` of `closeQueue()` (around line 256-257). Add immediately after:

```js
// ── Pin ─────────────────────────────────────────────────────

export function toggleQueuePin() {
  const pinned = !get('queuePinned');
  set('queuePinned', pinned);
  document.getElementById('app').classList.toggle('panel-queue-pinned', pinned);
  const btn = document.querySelector('.queue-pin-btn');
  btn?.setAttribute('aria-pressed', String(pinned));
  btn?.setAttribute('aria-label',
    pinned ? "Désépingler la file d'attente" : "Épingler la file d'attente");
}

export function clearQueuePin() {
  if (!get('queuePinned')) return;
  set('queuePinned', false);
  document.getElementById('app').classList.remove('panel-queue-pinned');
  const btn = document.querySelector('.queue-pin-btn');
  btn?.setAttribute('aria-pressed', 'false');
  btn?.setAttribute('aria-label', "Épingler la file d'attente");
}
```
