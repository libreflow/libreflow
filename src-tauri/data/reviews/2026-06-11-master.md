## Bugs corrigés

### CRITICAL

**[smtc.rs] Fuite fichier temp pochette sur Clear + shutdown**
`SmtcCmd::Clear` ne supprimait pas `prev_cover`. Le dernier `libreflow_smtc_*.jpg/png`
survivait dans %TEMP% apres stop et a la sortie de l'app.
Fix : `prev_cover.take()` + `fs::remove_file` ajoute dans le bras `Clear` ET apres
la boucle `while let Ok(cmd) = rx.recv()`.

### HIGH

**[smtc.rs] `app.manage()` apres `std::thread::spawn()`**
Ordering fragile : SmtcState n'etait enregistre qu'apres le spawn.
Fix : `app.manage()` deplace avant `std::thread::spawn()`.

**[smtc.rs] URI file:/// encoding incomplet**
Seulement 4 substitutions — parentheses, +, & dans le nom d'utilisateur Windows
produisaient une URI malformee (vignette SMTC muette).
Fix : table etendue a 15 substitutions couvrant tous les caracteres dangereux.

**[smtc.rs] Seek / SeekBy silencieusement ignores**
Les events SMTC/MPRIS seek relatif tombaient dans `_ => None`.
Fix Rust : arms `Seek(dir)` et `SeekBy(dir, duration)` ajoutent dans `dispatch_event`,
emettent `smtc-seek-by` (delta signe en secondes).
Fix JS : listener `smtc-seek-by` ajoute dans `boot()` (app.js) — clamp [0, duration].

### LOW

**[_patch_app.js]** Patch deja applique a app.js:1101-1104. Fichier supprime.
